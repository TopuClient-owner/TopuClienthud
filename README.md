# TopuHUD — Topu Client Utility Menu

## Minecraft 1.21.x
- 1.21.1
- 1.21.4
- 1.21.8
- 1.21.11

The `main` branch contains the stable 1.21.x line. Minecraft 26.x builds are maintained separately in the `all-version-support` branch.

Controls:
Right Shift = utility menu
Right Ctrl = HUD edit mode
Right Alt = toggle sneak

Features:
Armor HUD, FPS, Ping, TPS estimate, CPS, Combo, Totem counter,
Potion effects, Potion counter, Gapple counter, Auto Sprint,
Toggle Sneak, Armor durability warning at <=40%, Enemy health,
Attack cooldown.

Each module has an independent ON/OFF switch.
HUD positions are saved in config/topuhud.json.
